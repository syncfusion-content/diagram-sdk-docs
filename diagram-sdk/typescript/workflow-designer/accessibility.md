# Accessibility in TypeScript Workflow Designer control

The Workflow Designer announces selection and execution state changes through an ARIA live region, so screen reader users are informed when the selected step changes and as each step executes.

The canvas, toolbars, step collection and property panel are reachable with the keyboard, and the command palette provides keyboard access to the toolbar actions.
